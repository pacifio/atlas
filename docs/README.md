# docs

A map of this folder. For which doc answers which question, use the "Where the
answers live" table in `CLAUDE.md`; it is not repeated here.

- `architecture.md` - how a feature crosses the stack, and the file paths of each subsystem.
- `adr/` - architecture decision records, numbered in the order they were written. Each number is used once.
- `agents/` - how agents work with the issue tracker (Linear) and its labels.
- `reference/` - lookup material: design system, theme keys, configuration, keybindings, the gateway API.
- `archive/` - superseded specs and research, kept for the record. See its README.
- `requests/` - asks to other teams that the code cites. See its README.
- `qa/` - hardening and smoke reports per release. See its README.
- `research/` - findings from investigations, dated and sourced. See its README.
